# Instrucciones para Claude Code en este proyecto

- Antes de explorar el código fuente para responder preguntas sobre la arquitectura o el funcionamiento del proyecto, lee primero [README.md](README.md). Documenta la estructura de carpetas, el routing, los servicios, los modelos, el interceptor HTTP, el flujo de datos y las convenciones del proyecto.
- Solo vuelve a leer el código completo si el README no cubre lo preguntado, o si hay motivo para sospechar que el código cambió desde la última actualización del README (por ejemplo, commits recientes no reflejados ahí).
- Si haces un cambio que altera la arquitectura descrita (nuevas rutas, servicios, modelos, páginas, interceptores, cambios en el flujo de datos o en las convenciones), actualiza README.md en la misma tarea para que quede sincronizado.
